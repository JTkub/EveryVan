# เอกสารสำหรับอ่านโค้ด EveryVan

เริ่มจาก [คู่มืออ่านและอธิบายโค้ด](code-guide/README.md) หากต้องการเข้าใจว่าเว็บทำงานอย่างไรและจะเริ่มอ่านไฟล์ไหน คู่มือใช้ตัวอย่างจากโค้ดปัจจุบันและไล่ตั้งแต่หน้าจอไปจนถึงฐานข้อมูล

| ต้องการดูอะไร | เปิดเอกสารนี้ |
|---|---|
| ลำดับอ่านโค้ด คำศัพท์ และคำอธิบายการทำงานทีละขั้น | [คู่มืออ่านโค้ด](code-guide/README.md) |
| ค้นตำแหน่งฟังก์ชัน หน้าเว็บ และรายการ API | [ดัชนีโค้ดและ API](code-guide/REFERENCE.md) |
| ภาพว่าไฟล์และระบบเชื่อมกันอย่างไร | [แผนผังระบบ](architecture/README.md) |
| ติดตั้ง รันระบบ และสร้างผู้ดูแล | [README หลัก](../README.md) |
| สถานะการจอง การสแกน และจัดคิว | [State diagrams](../state-diagrams/README.md) |

คู่มืออ้างอิง source code ที่ตรวจวันที่ **15 ตุลาคม 2026** เมื่อแก้ implementation ควรปรับเอกสารและภาพที่เกี่ยวข้องตามด้วย
